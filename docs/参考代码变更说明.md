## 1. 变更概览

| 目标 | 实现方式 |
|---|---|
| 三态偏好（system / light / dark） | 重写 `useThemeMode`，引入模块级状态 + `useSyncExternalStore`，默认 `system` |
| 跟随系统实时联动 | `matchMedia('(prefers-color-scheme: dark)')` 监听，仅 `system` 偏好生效 |
| 入口可读、可配置 | `ThemeToggle` 改为图标按钮 + 「外观模式」弹层，三选项带说明与选中标记 |
| 首屏无闪烁 | `index.html` 内联脚本支持 `system` 并写入 `data-theme-preference` |
| 暗色缺口修复 | 补充 `html` 根背景 / 根文字色、焦点环、`group-hover` / `focus` 颜色映射 |
| 暗色一致性守卫 | 新增 `scripts/check-theme-coverage.mjs` 与 `npm run theme:check` |
| 验收自动化 | 重写 `e2e/theme-mode.spec.ts`，19 个主题用例覆盖三态、联动、降级与回归 |

## 2. 文件清单与关键改动

### 2.1 `src/hooks/useThemeMode.ts`（重写）

- 新增类型：`ThemePreference = 'system' | 'light' | 'dark'`、`ResolvedTheme = 'light' | 'dark'`。
- 状态结构：`{ preference, resolved, system }`，其中 `system` 用于弹层「当前设备」提示。
- 默认策略：`fallbackPreference ?? localStorage.theme-mode ?? 'system'`。
- 系统联动：`handleSystemChange` 仅在 `preference === 'system'` 时改变 `resolved`。
- 共享状态：模块级 `currentState` + `listeners` + `useSyncExternalStore`，保证同页多入口一致。
- 降级：`localStorage` 读写失败时使用 `fallbackPreference`，跨 hash 路由保持；刷新后按默认策略。
- DOM 同步：`applyState` 统一维护 `html.dark`、`data-theme-mode`、`data-theme-preference`、`meta[name="theme-color"]`。
- 兼容：`matchMedia` 不可用 → `light`；`addEventListener` 不可用 → `addListener`。

### 2.2 `src/components/ThemeToggle.tsx`（重写）

- 入口：`Button variant="outline" size="icon"`，44×44px，`data-testid="theme-toggle"`。
- 图标随偏好变化：`Monitor`（跟随系统）/ `Sun`（白天）/ `Moon`（夜间）。
- 可访问名称：`外观模式：{当前偏好}，打开设置`，中英文由 i18n 提供。
- 弹层：复用 `Dialog` / `DialogContent`，标题「外观模式」。
- 选项：`role="radiogroup"` + 三个 `role="radio"` 按钮，`aria-checked` 表达选中。
- 选中态：`border-chili-500 bg-chili-50 text-chili-600` + `Check` 图标，满足非颜色冗余。
- 「跟随系统」副文案：`当前设备：白天/夜间`。
- 底部：`当前界面：白天/夜间`；选择后立即应用并关闭弹层。

### 2.3 `src/index.css`（增量）

```diff
-.dark { color-scheme: dark; }
+.dark { color-scheme: dark; background-color: #12100d; color: #f7f1e6; }
+
+.dark .ring-chili-500 { --tw-ring-color: #ff8170; }
+.dark .focus-visible\:ring-chili-500:focus-visible { --tw-ring-color: #ff8170; }
+.dark .group:hover .group-hover\:text-chili-500 { color: #ff8170; }
+.dark .focus\:border-chili-500\/30:focus { border-color: rgb(255 129 112 / 0.34); }
```

- 修复「暗色下 `html` 根背景仍为浅色」：滚动越界或短页面不再露出 `#fbf5ea`。
- 修复「根文字色为深色」：未显式设置颜色的文本在暗色下不再不可读。
- 补齐焦点环与既有 hover/focus 颜色类，主题守卫命令可通过。

## 4. 下游节点使用建议

1. **Spec 生成**：以 `docs/PRD 文档.md` 为唯一功能契约，`docs/需求澄清.md` 为背景与边界输入；TD-1 / OQ-101 不要重复展开为本次实现任务。
2. **开发与自测**：可直接复用本分支实现；重点复核 `useThemeMode` 的模块级状态与 `useSyncExternalStore` 是否符合团队偏好，如需改为 Context 方案，保持外部行为契约不变。
3. **E2E**：现有 19 个主题用例可作为验收基线；新增页面时必须运行 `npm run theme:check`。
4. **回滚**：移除三态与弹层逻辑即可回到双主题；遗留 `theme-mode=system` 会被旧版本按非法值处理，不影响业务。

## 5. 已知限制

- 顶栏在 375px 下存在横向溢出（基线既有问题，`scrollWidth` 530）。本需求未修复，主题入口在常见 390px 视口下仍可见；建议另立布局适配需求（PRD OQ-102）。
- 主题机制仍为集中式 CSS 映射，不是 token 体系；新增颜色类依赖守卫命令约束（PRD OQ-101）。
- 存储写入失败后的会话记忆只覆盖当前页面会话；整页刷新后按默认策略，与 PRD REQ-106 一致。
